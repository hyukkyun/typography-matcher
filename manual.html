Typography Matcher 사용법

Google Fonts의 100여 개 폰트로 제목-본문 페어를 추천받고, 라이브 미리보기, 잠금 추천, 폰트 다운로드까지 한 곳에서.

시작하기

Typography Matcher는 Google Fonts의 카테고리(Serif / Sans-serif / Display / Handwriting / Monospace)별 약 100여 개 폰트를 큐레이션하고, 카테고리 대비 + 무드 매칭 알고리즘으로 어울리는 제목-본문 조합을 추천해주는 무료 웹 도구예요.

  • 한/영 폰트 98개 — 영문 75, 한글 23
  • 5개 카테고리, 추천 가능한 페어 9,506개
  • 다크 모드, 잠금 추천, 라이브 미리보기
  • 폰트별 @import URL 복사 / WOFF2 파일 다운로드
백엔드 없음. 모든 폰트는 Google Fonts CDN에서 직접 로드. 설치, 로그인, 회원가입 없이 바로 사용 가능.

빠른 시작

  1. 제목 폰트 선택 — 좌측 패널의 "제목 폰트" 피커를 클릭해서 폰트를 고르면 가운데 미리보기에 큰 글씨로 표시돼요.
  2. 본문 폰트 선택 — "본문 폰트" 피커에서 본문용 폰트를 골라요.
  3. ✨ 자동 추천 클릭 — 가운데 아래 버튼을 누르면 오른쪽에 어울리는 페어 9개가 추천돼요.
  4. 추천 카드 클릭 — 마음에 드는 페어를 클릭하면 제목/본문이 자동 적용되고 미리보기가 갱신돼요.
  5. 🔗 다운로드 링크 — 패널 헤더의 🔗 버튼으로 @import URL 복사하거나 폰트 파일을 받을 수 있어요.

인터페이스

세 개의 주요 영역으로 나뉘어요:

① 상단 바

  • 로고 + 타이틀 (좌측)
  • 한/영 토글, 🎲 랜덤, ⇄ 스왑, ❓ 매뉴얼, 🌙 테마 (우측)

② 좌측 컨트롤 패널

  • 제목 / 본문 폰트 피커
  • 크기 · 굵기 · 자간 슬라이더 (제목/본문 각각)
  • 샘플 텍스트 입력

③ 가운데 미리보기 + 우측 추천

  • 위: 메타 정보 (폰트명, 카테고리, 페어 점수)
  • 가운데: 실시간 타이포그래피 미리보기
  • 아래: ✨ 자동 추천 버튼
  • 우측: 추천 카드 그리드 (9개)

폰트 피커

버튼을 클릭하면 카테고리별 그룹으로 정렬된 폰트 목록이 떠요. 각 옵션이 자기 폰트로 이름이 표시돼서 어떤 폰트인지 한눈에 알 수 있어요.

카테고리

  • Serif — 명조, 격식. Playfair Display, Merriweather, Lora, Noto Serif KR, Nanum Myeongjo 등
  • Sans-serif — 고딕, 깔끔. Inter, Roboto, Montserrat, Noto Sans KR, Nanum Gothic 등
  • Display — 임팩트, 헤드라인. Bebas Neue, Oswald, Black Han Sans, Do Hyeon 등
  • Handwriting — 따뜻함, 캐주얼. Caveat, Dancing Script, Nanum Brush Script 등
  • Monospace — 코드, 에디토리얼. JetBrains Mono, Fira Code, Nanum Gothic Coding 등

한/영 필터 (상단 우측)

  • 전체 — 98개 모두
  • 한글 — 한글 지원 폰트 23개 (Noto Sans KR, Nanum Gothic, IBM Plex Sans KR 등)
  • 영문 — 영문 중심 폰트 75개 (Inter, Playfair Display, Bebas Neue 등)

필터를 바꾸면 드롭다운과 추천 결과가 함께 갱신돼요. 현재 선택한 폰트가 새 스크립트를 지원하지 않으면 자동으로 그 스크립트의 기본 폰트로 교체됩니다.

사용법

  • 열기 — 피커 버튼 클릭
  • 닫기 — 다시 클릭, ESC, 바깥 클릭
  • 잠긴 슬롯 — 🔒 상태에선 피커가 비활성 (클릭 안 됨)

폰트 큐레이션 (왜 98개?)

Google Fonts 전체 카탈로그는 1,500개+ 입니다. 이 중 98개를 선별한 데에는 의도적인 큐레이션 원칙이 있어요. 숫자 자체에 깊은 의미는 없고, 카테고리 균형과 실용성을 우선해서 채우다 보니 98에서 멈춘 거예요.

5가지 선정 기준

  1. 언어 한정 — 라틴 + 한글 위주. 아랍어 / 히브리어 / 태국어 / 데바나가리 / 티벳어 등 다른 문자 체계 폰트는 제외 (도구 용도와 안 맞음)
  2. 잘 알려진 폰트 — Playfair Display, Inter, Roboto, Bebas Neue, JetBrains Mono 처럼 디자이너들 사이에서 검증된 것 위주
  3. 카테고리 균형 — 5개 카테고리 × 라틴/한글 매트릭스에서 비어있는 칸 없이
  4. 무드 다양성 — editorial / friendly / tech / classic / retro 등 다양한 분위기 커버
  5. 실용성 — 실제로 프로젝트에 쓸 법한 것. 너무 특수한 폰트(예: 한 weight만 있거나 너무 장식적인 것) 제외

왜 1,500개가 아니라 98개?

규모이득손해
50개 (줄임)피커 가벼움, 추천 품질 ↑ (엄선)선택지 부족
98개 (현재)균형 잡힌 큐레이션특수한 폰트 없는 경우 있음
200개 (확장)선택지 풍성피커 스크롤 길어짐, 프리로드 트래픽 ↑
1,500개+ (전체)다 있음노이즈, 추천 품질 ↓, 아랍어 등 불필요

폰트 추가 / 제거하기

필요에 따라 직접 조정할 수 있어요.

A) data/fonts.js 직접 편집 (가장 간단)

배열에 한 줄씩 더하거나 빼면 끝:

// 추가 예시
{ name: 'Fraunces', category: 'serif', weights: [400, 700, 900],
  mood: ['editorial', 'elegant'], scripts: ['latin'] },

// 제거 예시 — 해당 줄을 통째로 삭제

수정 후 페이지 새로고침하면 즉시 반영돼요. 폰트는 자동으로 로드되고 추천 풀에도 포함됩니다.

B) Google Fonts Developer API로 전체 자동 로드

API 키를 발급받아 1,500+ 폰트를 동적으로 가져올 수 있어요.

GET https://www.googleapis.com/webfonts/v1/webfonts?key=YOUR_KEY
  • 장점: 1,500+ 다 가져옴, 자동 업데이트
  • 단점: API 키 등록 필요, 아랍어/히브리어 등 쓸데없는 것도 다 옴 (필터링 필요), 카테고리는 직접 매핑해야 함

C) ?subsets= 필터로 부분만 가져오기

API 호출 시 ?subsets=latin,korean으로 필터하면 라틴+한글만 약 600개. 추천 풀도 풍성해지고 스크롤도 감당 가능.

💡 추천: 지금 98개에 "없는 게 뭐가 있었으면 좋겠어?" 가 더 생산적인 질문이에요. 자주 쓰는 폰트나 추가하고 싶은 무드가 있으면 data/fonts.js에 직접 추가하는 게 가장 빠르고 안전해요. 카테고리별 5~10개씩 더 추가하면 130~150개 정도가 추천 적정선이에요.

스타일 조정

각 슬라이더는 제목/본문 각각 별도로 조절돼요. 폰트를 고른 뒤 미세 조정에 사용하세요.

크기

  • 제목: 20 ~ 120px
  • 본문: 12 ~ 32px

굵기

100 ~ 900 (10단계). Google Fonts에서 실제로 제공하는 weight만 의미 있게 적용돼요 — 예를 들어 Bebas Neue는 400만 있어서 슬라이더를 움직여도 외관은 바뀌지 않아요.

자간

-0.05em ~ 0.20em 범위. 제목은 타이트하게(음수), 본문은 약간 트게(양수) 주는 게 일반적이에요.

샘플 텍스트

한/영 토글에 따라 자동으로 그 스크립트의 예문이 들어가요. 직접 입력 가능 — 한 번 편집하면 모드 전환해도 유지돼요.

잠금과 추천

패널 헤더의 🔓 버튼으로 제목/본문 폰트를 고정할 수 있어요. 자동 추천이 잠긴 슬롯은 건드리지 않고, 나머지 슬롯만 추천해줘요.

3가지 추천 모드

모드동작추천 헤더
둘 다 자유 큐레이션 5개 + 랜덤 고득점 4개를 셔플해서 9개 표시 에디토리얼 추천 / 한글 추천 페어 / 영문 추천 페어
제목만 🔒 잠긴 제목에 어울리는 본문 9개 추천 🔒 "Playfair Display" 고정 — 어울리는 본문
본문만 🔒 잠긴 본문에 어울리는 제목 9개 추천 🔒 "Nanum Gothic" 고정 — 어울리는 제목
둘 다 🔒 추천 중지 + 해제 안내 🔒 모두 고정됨

추천 카드 동작

  • 매 ✨ 자동 추천 클릭마다 다른 9개 표시 (셔플 + 랜덤)
  • 카드 클릭 시: 잠금 안 된 슬롯만 변경, 잠긴 슬롯은 유지
  • 잠긴 폰트는 카드에서 흐리게(0.45) + 🔒 표시로 구분

🎲 랜덤 / ⇄ 스왑

  • 랜덤 — 잠금 안 된 슬롯을 무작위로. 제목 잠금이면 본문만 변경
  • 스왑 — 제목 ↔ 본문 교환. 잠금이 하나라도 있으면 비활성 + 플래시 메시지

폰트 다운로드

패널 헤더의 🔗 버튼을 누르면 작은 팝오버가 떠요. 현재 선택된 폰트에 대해 세 가지 작업을 할 수 있습니다.

📋 URL 복사

Google Fonts CSS API의 @import URL을 클립보드로 복사. 예:

https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;700;900&display=swap

HTML <link> 또는 CSS @import로 바로 사용 가능.

⬇ 폰트 받기

Google Fonts CSS에서 첫 번째 @font-face의 src url()을 추출해서 fonts.gstatic.com에서 파일을 받아요. 확장자는 CSS의 format() 토큰 기준으로 정확히 결정됩니다.

  • 모던 브라우저 (Chrome / Safari / Firefox / Edge) → woff2
  • 구형 브라우저 (IE 11) → woff
  • 파일명에 정확한 확장자 적용: Playfair-Display.woff2
TTF가 필요한 경우: Google Fonts API는 더 이상 TTF를 제공하지 않아요. 디자인 툴(Figma, Sketch, Adobe) 호환을 위해 TTF가 꼭 필요하면 ↗ Google Fonts 링크로 공식 페이지에서 직접 받으세요.

↗ Google Fonts

공식 specimen 페이지를 새 탭으로 열어요. 모든 weight, italic, glyph 미리보기, 그리고 TTF 수동 다운로드가 가능.

자주 묻는 질문

Q. 폰트 개수와 조합 수는?
98개 폰트 (영문 75 + 한글 23). 5개 카테고리. 추천 가능한 페어 9,506개 (영문 5,550 + 한글 506 + 크로스 스크립트 3,450). 80점 이상 고득점 페어 2,565개. 왜 98개인지에 대한 자세한 선정 기준은 폰트 큐레이션 섹션 참고.
Q. 점수는 어떻게 매기나요?
(1) 카테고리 페어 점수 (가장 큰 비중), (2) 무드 교집합 보너스, (3) 같은 패밀리 보너스, (4) 비추천 조합 감점. 자세한 점수표는 기술 노트 참고.
Q. 페어링 추천 알고리즘이 뭔가요?
휴리스틱 기반 (ML 아님). 타이포그래피 베스트 프랙티스에서 검증된 페어를 점수표로 정의. 자동 추천은 큐레이션 프리셋 5개 + 라이브러리 무작위 추출 50쌍의 상위 4개를 셔플해서 9개 표시.
Q. 한글 폰트 추천이 좀 부족한 것 같아요
Google Fonts가 제공하는 한글 폰트가 23개로 제한적이에요. Pretendard, Spoqa Han Sans Neo 같은 인기 폰트는 Google Fonts에 없어서 큐레이션에 포함 못 했습니다. 직접 추가하려면 data/fonts.js에 항목을 더하고 app.js의 폰트 라이브러리에 등록하면 돼요.
Q. TTF로 다운로드가 안 돼요
Google Fonts API는 WOFF2/WOFF만 제공 (User-Agent 기준). 브라우저의 fetch()는 User-Agent 헤더가 forbidden이라 변경 불가능. TTF가 꼭 필요하면 ↗ Google Fonts 링크로 공식 페이지에서 직접 받기.
Q. 배포 URL이 영원한가요?
매 배포마다 새 URL이 생성돼요 (이전 URL은 사용 불가). 영구 호스팅이 필요하면 GitHub Pages, Netlify, Vercel, Cloudflare Pages 같은 정적 호스팅 서비스를 추천.
Q. 오프라인에서도 쓸 수 있나요?
폰트가 Google Fonts CDN에서 로드되기 때문에 인터넷 필요. 오프라인 사용은 정식 호스팅으로 가져간 뒤 fonts.js와 loader.js를 수정해서 로컬 폰트 파일을 가리키게 변경하면 가능.

monospace → serif66에디토리얼 대비
sans-serif → sans-serif64톤 통일 (의도적)
display → display20비추 (overwhelming)
handwriting ↔ *10-30비추 (clash)

그 위에 무드 교집합 보너스(1개당 +3, 최대 +9), 같은 패밀리 보너스(+5) 등이 더해져요. 같은 폰트 두 번 추천은 0점으로 컷.

Google Fonts API
