Typography Matcher 사용법

Google Fonts 98선 + Noonnu 인기 한글 폰트 100선, 총 198개로 제목-본문 페어를 추천받고, 라이브 미리보기, 잠금 추천, 폰트 다운로드까지 한 곳에서.

시작하기

Typography Matcher는 Google Fonts 98선 + Noonnu 인기 한글 폰트 100선을 큐레이션하고, 카테고리 대비 + 무드 매칭 알고리즘으로 어울리는 제목-본문 조합을 추천해주는 무료 웹 도구예요. 영문/국제 폰트는 Google Fonts에서, 한글 폰트는 Noonnu(눈누)에서 가져옵니다.

  • 총 198개 — Google Fonts 98 + Noonnu 100
  • 5개 카테고리 (Serif / Sans-serif / Display / Handwriting / Monospace)
  • 다크 모드, 잠금 추천, 라이브 미리보기
  • 폰트별 @import URL 또는 @font-face 스니펫 복사 / WOFF2 파일 다운로드
두 폰트 CDN. Google Fonts는 Google CDN, Noonnu는 jsdelivr CDN에서 직접 로드. 설치, 로그인, 회원가입 없이 바로 사용 가능.

빠른 시작

  1. 제목 폰트 선택 — 좌측 패널의 "제목 폰트" 피커를 클릭해서 폰트를 고르면 가운데 미리보기에 큰 글씨로 표시돼요.
  2. 본문 폰트 선택 — "본문 폰트" 피커에서 본문용 폰트를 골라요.
  3. ✨ 자동 추천 클릭 — 가운데 아래 버튼을 누르면 오른쪽에 어울리는 페어 9개가 추천돼요.
  4. 추천 카드 클릭 — 마음에 드는 페어를 클릭하면 제목/본문이 자동 적용되고 미리보기가 갱신돼요.
  5. 🔗 다운로드 링크 — 패널 헤더의 🔗 버튼으로 @import URL 복사하거나 폰트 파일을 받을 수 있어요.

인터페이스

세 개의 주요 영역으로 나뉘어요:

① 상단 바

  • 로고 + 타이틀 (좌측)
  • 한/영 토글, 🎲 랜덤, ⇄ 스왑, ❓ 매뉴얼, 🌙 테마 (우측)

② 좌측 컨트롤 패널

  • 제목 / 본문 폰트 피커
  • 크기 · 굵기 · 자간 슬라이더 (제목/본문 각각)
  • 샘플 텍스트 입력

③ 가운데 미리보기 + 우측 추천

  • 위: 메타 정보 (폰트명, 카테고리, 페어 점수)
  • 가운데: 실시간 타이포그래피 미리보기
  • 아래: ✨ 자동 추천 버튼
  • 우측: 추천 카드 그리드 (9개)

폰트 피커

버튼을 클릭하면 카테고리별 그룹으로 정렬된 폰트 목록이 떠요. 각 옵션이 자기 폰트로 이름이 표시돼서 어떤 폰트인지 한눈에 알 수 있어요.

카테고리

  • Serif — 명조, 격식. Playfair Display, Merriweather, Lora, Noto Serif KR, Nanum Myeongjo 등
  • Sans-serif — 고딕, 깔끔. Inter, Roboto, Montserrat, Noto Sans KR, Nanum Gothic 등
  • Display — 임팩트, 헤드라인. Bebas Neue, Oswald, Black Han Sans, Do Hyeon 등
  • Handwriting — 따뜻함, 캐주얼. Caveat, Dancing Script, Nanum Brush Script 등
  • Monospace — 코드, 에디토리얼. JetBrains Mono, Fira Code, Nanum Gothic Coding 등

한/영 필터 (상단 우측)

  • 전체 — 98개 모두
  • 한글 — 한글 지원 폰트 23개 (Noto Sans KR, Nanum Gothic, IBM Plex Sans KR 등)
  • 영문 — 영문 중심 폰트 75개 (Inter, Playfair Display, Bebas Neue 등)

필터를 바꾸면 드롭다운과 추천 결과가 함께 갱신돼요. 현재 선택한 폰트가 새 스크립트를 지원하지 않으면 자동으로 그 스크립트의 기본 폰트로 교체됩니다.

사용법

  • 열기 — 피커 버튼 클릭
  • 닫기 — 다시 클릭, ESC, 바깥 클릭
  • 잠긴 슬롯 — 🔒 상태에선 피커가 비활성 (클릭 안 됨)

폰트 큐레이션 (왜 198개?)

두 폰트 소스를 합쳐서 총 198개를 제공해요.

  • Google Fonts 98선 — 영문/국제 폰트 중심. Playfair Display, Inter, Roboto, Bebas Neue, JetBrains Mono 같은 검증된 디자이너 폰트.
  • Noonnu 인기 100선 — 한국에서 가장 인기 있는 한글 폰트. Pretendard, Paperlogy, GmarketSans, SUIT, S-CoreDream, LeeSeoyun, KoPubDotum 등.

Google Fonts가 한글 폰트를 23개만 제공하는 반면, Noonnu는 수백 개의 한글 폰트를 보유한 한글 폰트 전문 큐레이션 사이트예요. 두 소스를 합쳐서 한/영 + 인기/클래식 폭넓게 커버합니다.

5가지 선정 기준

  1. 언어 한정 — 라틴 + 한글 위주. 아랍어 / 히브리어 / 태국어 / 데바나가리 / 티벳어 등 다른 문자 체계 폰트는 제외
  2. 잘 알려진 폰트 — 디자이너들 사이에서 검증된 것 위주 (Google Fonts) + Noonnu 인기순 상위 100위 (한글)
  3. 카테고리 균형 — 5개 카테고리 × 라틴/한글 매트릭스에서 비어있는 칸 없이
  4. 무드 다양성 — editorial / friendly / tech / classic / retro / playful 등 다양한 분위기 커버
  5. 실용성 — 실제로 프로젝트에 쓸 법한 것. 너무 특수한 폰트(예: 한 weight만 있거나 너무 장식적인 것) 제외

상단 토글에서 전체 / Google / 눈누로 필터할 수 있어요. Picker에서 Noonnu 폰트는 N 배지가 붙어서 한눈에 구분됩니다.

폰트 추가 / 제거하기

필요에 따라 직접 조정할 수 있어요.

A) data/fonts.js (Google) / data/noonnuFonts.js (Noonnu) 직접 편집

배열에 한 줄씩 더하거나 빼면 끝:

// Google Fonts 추가 예시
{ name: 'Fraunces', category: 'serif', weights: [400, 700, 900],
  mood: ['editorial', 'elegant'], scripts: ['latin'], source: 'google' },

// Noonnu 추가 예시
{ name: 'MyFont', category: 'sans-serif', weights: [400],
  mood: ['modern'], scripts: ['korean'], source: 'noonnu',
  src: 'https://cdn.jsdelivr.net/gh/.../MyFont.woff2',
  pageUrl: 'https://noonnu.cc/font_page/1234' },

수정 후 페이지 새로고침하면 즉시 반영돼요.

B) Google Fonts Developer API로 전체 자동 로드

API 키를 발급받아 1,500+ 폰트를 동적으로 가져올 수 있어요.

GET https://www.googleapis.com/webfonts/v1/webfonts?key=YOUR_KEY
  • 장점: 1,500+ 다 가져옴, 자동 업데이트
  • 단점: API 키 등록 필요, 아랍어/히브리어 등 쓸데없는 것도 다 옴 (필터링 필요), 카테고리는 직접 매핑해야 함

C) Noonnu 인기순 더 가져오기

Noonnu의 ?order_by=pd 페이지는 Stimulus 동적 로딩이라 일반 ?page=2로는 페이지네이션이 안 돼요. ?order_by=pd&page=2 형태로 URL에 page 파라미터를 직접 주면 페이지가 로드되긴 하지만, 각 페이지 HTML을 data/noonnuFonts.js에 수동으로 합치는 방식이 가장 안정적이에요.

💡 두 소스의 차이: Google Fonts는 weight가 다양 (예: Inter는 100~900), Noonnu는 단일 weight (400)가 대부분. Noonnu 폰트는 한글 디자인이 강점이라 영문 glyph는 약할 수 있어요. 제목은 한글/디자인 폰트, 본문은 Google Fonts 영문 폰트로 페어링하는 것도 한 방법이에요.

스타일 조정

각 슬라이더는 제목/본문 각각 별도로 조절돼요. 폰트를 고른 뒤 미세 조정에 사용하세요.

크기

  • 제목: 20 ~ 120px
  • 본문: 12 ~ 32px

굵기

100 ~ 900 (10단계). Google Fonts에서 실제로 제공하는 weight만 의미 있게 적용돼요 — 예를 들어 Bebas Neue는 400만 있어서 슬라이더를 움직여도 외관은 바뀌지 않아요.

자간

-0.05em ~ 0.20em 범위. 제목은 타이트하게(음수), 본문은 약간 트게(양수) 주는 게 일반적이에요.

샘플 텍스트

한/영 토글에 따라 자동으로 그 스크립트의 예문이 들어가요. 직접 입력 가능 — 한 번 편집하면 모드 전환해도 유지돼요.

잠금과 추천

패널 헤더의 🔓 버튼으로 제목/본문 폰트를 고정할 수 있어요. 자동 추천이 잠긴 슬롯은 건드리지 않고, 나머지 슬롯만 추천해줘요.

3가지 추천 모드

모드동작추천 헤더
둘 다 자유 큐레이션 5개 + 랜덤 고득점 4개를 셔플해서 9개 표시 에디토리얼 추천 / 한글 추천 페어 / 영문 추천 페어
제목만 🔒 잠긴 제목에 어울리는 본문 9개 추천 🔒 "Playfair Display" 고정 — 어울리는 본문
본문만 🔒 잠긴 본문에 어울리는 제목 9개 추천 🔒 "Nanum Gothic" 고정 — 어울리는 제목
둘 다 🔒 추천 중지 + 해제 안내 🔒 모두 고정됨

추천 카드 동작

  • 매 ✨ 자동 추천 클릭마다 다른 9개 표시 (셔플 + 랜덤)
  • 카드 클릭 시: 잠금 안 된 슬롯만 변경, 잠긴 슬롯은 유지
  • 잠긴 폰트는 카드에서 흐리게(0.45) + 🔒 표시로 구분

🎲 랜덤 / ⇄ 스왑

  • 랜덤 — 잠금 안 된 슬롯을 무작위로. 제목 잠금이면 본문만 변경
  • 스왑 — 제목 ↔ 본문 교환. 잠금이 하나라도 있으면 비활성 + 플래시 메시지

폰트 다운로드

패널 헤더의 🔗 버튼을 누르면 작은 팝오버가 떠요. 현재 선택된 폰트에 대해 세 가지 작업을 할 수 있습니다. 소스(Google / Noonnu)에 따라 동작이 조금 달라요.

📋 URL / 코드 복사

Google Fonts — CSS API의 @import URL을 클립보드로 복사:

https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;700;900&display=swap

HTML <link> 또는 CSS @import로 바로 사용 가능.

Noonnu — jsdelivr CDN은 .woff/.woff2 파일이라 @import로 못 씁니다. 대신 @font-face 스니펫을 복사:

@font-face {
  font-family: 'Pretendard';
  src: url('https://cdn.jsdelivr.net/gh/projectnoonnu/pretendard@1.0/Pretendard-Regular.woff2') format('woff2');
  font-display: swap;
}

이걸 본인 CSS에 붙여넣고 font-family: 'Pretendard', sans-serif;로 사용.

⬇ 폰트 받기

Google Fonts — Google Fonts CSS에서 첫 번째 @font-face의 src url()을 추출해서 fonts.gstatic.com에서 파일을 받아요. 확장자는 CSS의 format() 토큰 기준으로 정확히 결정됩니다.

  • 모던 브라우저 (Chrome / Safari / Firefox / Edge) → woff2
  • 구형 브라우저 (IE 11) → woff

Noonnu — src URL에서 직접 fetch해서 받습니다. jsdelivr는 WOFF2/WOFF/OTF/TTF 확장자를 정확히 노출하니 그대로 저장.

TTF가 필요한 경우: Google Fonts API는 WOFF2/WOFF만 제공 (User-Agent 기준). Noonnu는 원본이 TTF/OTF인 경우도 있어요. TTF가 꼭 필요하면 ↗ Google Fonts / ↗ Noonnu 링크로 공식 페이지에서 직접 받으세요.

↗ Google Fonts / ↗ Noonnu

소스에 따라 다른 페이지로 이동:

  • Google Fonts — 공식 specimen 페이지. 모든 weight, italic, glyph 미리보기, TTF 수동 다운로드.
  • Noonnu — 상세 페이지. 라이선스, 제작자, 원본 파일(일부 TTF 제공) 확인 가능.

자주 묻는 질문

Q. 폰트 개수와 조합 수는?
198개 폰트 (Google Fonts 98 + Noonnu 100). 5개 카테고리. Google Fonts 영문 75 + 한글 23, Noonnu 한글 100. 왜 198개인지에 대한 자세한 선정 기준은 폰트 큐레이션 섹션 참고.
Q. 점수는 어떻게 매기나요?
(1) 카테고리 페어 점수 (가장 큰 비중), (2) 무드 교집합 보너스, (3) 같은 패밀리 보너스, (4) 비추천 조합 감점. 자세한 점수표는 기술 노트 참고.
Q. 페어링 추천 알고리즘이 뭔가요?
휴리스틱 기반 (ML 아님). 타이포그래피 베스트 프랙티스에서 검증된 페어를 점수표로 정의. 자동 추천은 큐레이션 프리셋 5개 + 라이브러리 무작위 추출 50쌍의 상위 4개를 셔플해서 9개 표시.
Q. 한글 폰트 추천이 부족한 것 같아요
v2에서 Noonnu 인기 100선을 추가해서 한글 폰트가 총 123개 (Google 23 + Noonnu 100)로 늘었어요. Pretendard, Paperlogy, GmarketSans, SUIT, S-CoreDream, LeeSeoyun, KoPubDotum 같은 인기 폰트가 다 포함돼 있어요. 상단 토글에서 눈누만 선택하면 한글 폰트만 볼 수 있어요.
Q. TTF로 다운로드가 안 돼요
Google Fonts API는 WOFF2/WOFF만 제공 (User-Agent 기준). 브라우저의 fetch()는 User-Agent 헤더가 forbidden이라 변경 불가능. TTF가 꼭 필요하면 ↗ Google Fonts / ↗ Noonnu 링크로 공식 페이지에서 직접 받기.
Q. 배포 URL이 영원한가요?
매 배포마다 새 URL이 생성돼요 (이전 URL은 사용 불가). 영구 호스팅이 필요하면 GitHub Pages, Netlify, Vercel, Cloudflare Pages 같은 정적 호스팅 서비스를 추천.
Q. 오프라인에서도 쓸 수 있나요?
폰트가 Google Fonts / jsdelivr CDN에서 로드되기 때문에 인터넷 필요. 오프라인 사용은 정식 호스팅으로 가져간 뒤 fonts.js / noonnuFonts.js와 loader.js를 수정해서 로컬 폰트 파일을 가리키게 변경하면 가능.

기술 노트

이 도구가 어떻게 만들어졌는지 궁금한 분들을 위한 섹션이에요.

페어링 점수표 (PAIR_SCORE)

제목 → 본문 카테고리 조합별 베이스 점수:

제목 → 본문점수의미
serif → sans-serif92에디토리얼 클래식
sans-serif → serif90모던 에디토리얼
display → sans-serif88임팩트 + 가독성
display → serif82패션 에디토리얼
monospace → sans-serif80테크 에디토리얼
handwriting → sans-serif78따뜻함 + 가독
serif → serif68톤 통일 (의도적)
monospace → serif66에디토리얼 대비
sans-serif → sans-serif64톤 통일 (의도적)
display → display20비추 (overwhelming)
handwriting ↔ *10-30비추 (clash)

그 위에 무드 교집합 보너스(1개당 +3, 최대 +9), 같은 패밀리 보너스(+5) 등이 더해져요. 같은 폰트 두 번 추천은 0점으로 컷.

Google Fonts API

  • CSS API: https://fonts.googleapis.com/css2?family=Font+Name:wght@400;700&display=swap
  • 모던 브라우저는 WOFF2, 구형은 WOFF 반환 (User-Agent 기준)
  • document.fonts.ready로 폰트 로딩 완료 감지
  • IE 11 미지원

Noonnu (jsdelivr CDN)

  • CDN URL: https://cdn.jsdelivr.net/gh/projectnoonnu/{repo}@{ver}/{font}.woff2
  • Noonnu가 GitHub에 호스팅한 폰트를 jsdelivr가 CDN으로 미러링
  • 폰트별로 <style>@font-face{...}</style>을 동적 주입 (CSS API 미사용)
  • CORS 허용 — 직접 fetch & 다운로드 가능
  • WOFF2, WOFF, OTF, TTF 모두 지원 (폰트별 상이)

기술 스택

  • Vanilla JavaScript (ES2020+) — 프레임워크 없음
  • CSS Custom Properties (테마 시스템)
  • Google Fonts CSS API + jsdelivr CDN (Noonnu)
  • Canvas API (현재 버전에서는 미사용)

Built with vanilla JS + Google Fonts. 폰트 라이선스는 각 Google Fonts 항목의 라이선스를 따릅니다. 도구 자체 코드는 자유롭게 참고/수정 가능.
